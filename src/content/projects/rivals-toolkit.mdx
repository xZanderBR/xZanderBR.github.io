## The problem

Modding Marvel Rivals means working with Unreal Engine 5 packages: pak and IoStore containers, compressed with Oodle and sometimes encrypted. The tools that existed were command-line only and split across several projects. Players wanted one app that could install, inspect and edit mods without breaking their game files.

## What I built

- A desktop app (Tauri and React) and a CLI on top of one Rust engine, organized as a Cargo workspace: `rivals-core`, `rivals-uasset` and `rivals-cli`.
- Binary readers and writers for pak and IoStore containers, with Oodle compression and encrypted containers.
- An editor for UE5 packages: Blueprint scripts as text, textures, meshes and audio.
- A file browser that stays smooth with 10,000+ entries through virtualized rendering. Long jobs run on background threads and report progress over Tauri IPC.
- A self-updater, and crash-log analysis that names the mod behind a crash.
