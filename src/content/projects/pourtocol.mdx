## The problem

A drink dispenser that several people can order from at once, from their phones. The hardware is an ESP32 driving a pump, a distance sensor and an NFC reader, and it can only answer so many requests before it falls behind.

## What I built

- A React and TypeScript web app for ordering and live status.
- A Python Flask coordinator between the web app and the device. It talks to the ESP32 over HTTP and finds it on the network with mDNS.
- The firmware and hardware (relay pump, ultrasonic sensor, NFC) were built with a teammate.

## Results

- Cut round-trips to the ESP32 by about 80% under multi-client polling, with a single-flight status cache, persistent keep-alive sessions and cached mDNS lookups.
